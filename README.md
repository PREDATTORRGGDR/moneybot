# Бот активации кошелька

Telegram-бот (aiogram 3) продаёт 0.1 GRAM для активации кошелька «Деньги». Оплата: Stars, перевод на карту с PDF-чеком, по желанию GRAM/TON, или бесплатно за приглашённых друзей. Разделы: **Активация**, **Отзывы**, **Поддержка**.

## Как работает заказ
1. Покупатель жмёт «Активация», выбирает оплату, вводит @username или адрес (или «Себе») и подтверждает.
2. Оплата:
   - **Stars**: бот выставляет счёт в ⭐, оплата приходит на баланс бота.
   - **Карта**: бот показывает реквизиты, покупатель присылает **PDF-чек** (скриншот не принимается). Админам приходит чек с кнопками «✅ Оплата пришла» / «❌ Чек не подходит».
   - **GRAM**: бот показывает адрес и код-комментарий, после перевода покупатель жмёт «Я оплатил», бот сам проверяет платёж через toncenter.
   - **Бесплатно (за рефов)**: если человек пригласил нужное число друзей, заказ создаётся сразу, приглашённые списываются.
   - **Бесплатно (за комментарии)**: человек оставляет N комментариев с рекламой бота в TikTok под видео про Telegram-карты и присылает скриншот каждого (одинаковые файлы не считаются). Набрал N: «Отправить на проверку», админам приходят все скрины и кнопки «✅ Засчитать» / «❌ Отклонить». Один раз на человека, после отказа можно подать снова с новыми скринами.
3. Всем админам приходит «💰 Новая покупка» с кнопками **✅ Отправил**, **↩️ Вернуть Stars** (или **❌ Отменить**) и **🔍 Найти покупателя**. Нажал один админ: отметка («✅ Выполнено (Имя)») появляется у всех, кнопки пропадают.
4. Админ вручную отправляет GRAM и жмёт «Отправил», покупателю приходит уведомление и кнопка «Оставить отзыв».

Заказ (и его номер) появляется только когда пришла оплата или чек: неоплаченные заказы не хранятся. Номер заказа видят только админы.

Экраны меняются в одном сообщении (баннер остаётся), а не удаляются.

Пользоваться ботом можно только с подпиской на канал `REQUIRED_CHANNEL` (бот должен быть его админом). Без подписки бот показывает экран «Подпишись» и кнопку «Я подписался». Оплата Stars и присланные файлы (PDF-чеки) проходят всегда, чтобы не потерять деньги. Если бот не может проверить подписку (его убрали из админов), он никого не блокирует.

## Для админа
- `/admin`: статистика (сегодня, 7 и 30 дней, всё время; ⭐, ₽ и GRAM отдельно), заказы, которые ждут отправки, и «📋 Все заказы» с листанием.
- `/admin` → «📢 Рассылка всем»: присылаешь любое сообщение (текст, фото, видео, файл), бот показывает превью и после «Отправить всем» копирует его каждому пользователю, потом присылает итог (доставлено, заблокировали бота).
- `/admin` → «⚙️ Цены и способы оплаты»: цена в Stars, GRAM и ₽, сколько приглашённых и сколько комментариев нужно для бесплатной активации, включение и выключение Stars / GRAM / карты / «за рефов» / «за комменты». Хранится в `bot.db`. GRAM и карту можно включить, только если в `.env` есть `TON_WALLET` / `CARD_NUMBER`.
- `/ref` (для всех): личная реф. ссылка `t.me/<бот>?start=ref_<id>` и счётчик. Засчитывается только новый человек; если админ отменит бесплатный заказ, приглашённые вернутся.
- `/user <id>` или `/user @ник`: актуальный профиль человека по ID (ник мог смениться после заказа), его заказы и кнопка «Написать через бота». Ищет и по старому нику.
- Алерты: новый пользователь (с источником из ссылки `t.me/<бот>?start=<метка>`) и каждая покупка. `NEW_USER_ALERTS_OFF` выключает алерт о новых пользователях выбранным админам.
- Что пользователь пишет боту вне меню, приходит админам с кнопкой «Ответить».
- `/seticon`, `/icons`: премиум-эмодзи в текстах и иконки на кнопках (`icons.json`).

## Запуск
1. Создай бота у @BotFather, поставь аватарку `assets/avatar.png` (`/setuserpic`).
2. Скопируй `.env.example` в `.env` и заполни.
3. Если отзывы публикуются в канал, добавь бота админом в этот канал.

Docker (так он работает на сервере):

```powershell
docker build -t moneybot .
```

```powershell
docker run -d --name moneybot --restart always --memory 256m -v ${PWD}:/app moneybot
```

Локально:

```powershell
python -m venv .venv; .venv\Scripts\pip install -r requirements.txt; .venv\Scripts\python bot.py
```

`assets/banner.png` это картинка главного меню. Заказы и пользователи хранятся в `bot.db` (SQLite, создаётся сам, в репо не попадает).

## Как вносить правки и деплоить
Рабочая папка на компьютере это клон этого репо (`D:\moneybot`). На сервере `/root/moneybot` тоже клон, рядом с кодом там лежат `.env` и `bot.db`, git их не трогает. Руками на сервере файлы не правим.

1. Правишь код в `D:\moneybot`.
2. Коммитишь и пушишь:

```powershell
git add -A; git commit -m "что поменял"; git push
```

3. Выкатываешь на сервер (git pull там и рестарт бота, при новых зависимостях пересборка образа):

```powershell
.\deploy.ps1
```

Цены меняются в `/admin`. Реквизиты и токен живут в `.env` на сервере, их меняют там, потом `ssh looksmax "docker restart moneybot"`.

## Как прислать изменение
Сделай форк, внеси правку и открой pull request. Секреты (`.env`) и базу (`bot.db`) не коммить.
